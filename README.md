# pair-wise-yf-58 功能开关和灰度发布控制台

## 源提示词摘要
产品负责人配置目标用户、地区、应用版本和依赖条件，研发负责人审批发布计划，值班人员观察过程并随时关闭开关。系统支持规则组合、流量逐步增加、定时生效、紧急停止、回滚，并能在保存前模拟不同用户的命中版本。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 分档灰度编排（src/services/rollout.ts）
纯函数引擎，所有状态变更都经由它，Pinia 只做持久化与界面接线：

- **发布计划分档**：每档写清放量比例与观察时长，比例严格递增、末档必须 100%；开始灰度只进入第 1 档（默认 1% / 30 分钟 → 10% / 60 → 50% / 120 → 100% / 240），杜绝一次全放。
- **观察期门禁**：观察时间未满不能推进；走满时错误率不低于门禁，自动退回上一档并冻结，冻结后推进/停止/继续观察全部拦截。
- **命中范围与快照收回**：回退按新旧比例生成逐桶收回任务（用户范围 + 快照载荷）；收回失败立即停在断点，可从断点重试，剩余项保留为待收。
- **档位变化重算**：解除冻结重新推进后，未收完的快照按新档位重算——重新落入命中范围的标 `recalculated` 作废，范围外的重算载荷后继续待收；已收回的不动。
- **双人值班仲裁（乐观锁 `rev`）**：两个值班员同时提交推进或停止时，只让 rev 匹配当前档位的第一个操作落地；后到指令返回 `stale-rejudged`，不落地并按新档位重新判定。
- **审计去重**：每次回退只写一条审计；收回重试、快照重算只记任务日志，不产生审计。

## 已实现闭环
- 功能开关、发布计划（含分档/门禁/运行时）、审计记录三类业务对象。
- 规则组合、模拟用户命中、分档放量、定时生效、观察门禁、双人指令仲裁。
- 紧急停止、回退一档冻结、解除冻结重观察、命中快照收回/断点重试/档位重算。
- 产品/研发双审批、离线提示、VeeValidate + Zod 精确校验和 localStorage 持久化（旧数据自动补齐分档字段）。
